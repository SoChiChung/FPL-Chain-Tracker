## 实时数据层：从「静态快照」升级为「按需实时」

**起因**：`npm run start` 不更新数据（该命令只起静态服务器），且仓库里一份 `data/` 都没有
（`git ls-files` 无 `data/*`，3 次提交均非 Actions 机器人），直接部署会白屏。

**关键技术约束（实测，别再走弯路）**：
FPL 官方 API **不返回 CORS 头**——
`GET /api/entry/7557100/` 与 `/api/bootstrap-static/` 的响应头里没有 `Access-Control-Allow-Origin`，
`Vary` 是 `X-API-Language, Accept-Encoding`（不含 `Origin`，不是条件性 CORS）。
→ **浏览器不能直连官方 API**，任何「前端自己拉实时数据」的方案都必须有服务端代理。
（`/api/event-status/` 只有 224 字节，但只有 `bonus_added`/当前 event，判定不了 `finished`，不能替代 bootstrap。）

**落地方案（主人选定）**：Vercel 无服务器代理 + 前端按 GW 阶段自适应缓存。

| 文件 | 职责 |
|---|---|
| `lib/fpl-core.js` | `crawler/*.py` 的同源 JS 实现：`classifyEvent` / `determinePhase` / `computeManagerStats` / `computeSeasonTotals` / `computeScores` / `assemble` / `collectLive` |
| `api/fpl-live.js` | Vercel 函数，`?file=meta.json\|summary.json\|stats.json\|gw-NN.json`，输出与 `data/*.json` 同构；带 `X-FPL-Phase` / `X-FPL-Source` 头 |
| `scripts/live-server.js` | 本地预览线上行为（静态 + 实时接口同端口，默认 8001） |
| `scripts/verify-live.js` | 验证脚本，`npm run verify` |

**缓存/刷新口径**（`determinePhase`，前端 `phaseFromSummary` 同口径）：
- `live`：有 GW 正在进行 → 函数缓存 30s、前端 60s 轮询
- `settling`：最近 GW 已 finished 但未 sealed（补分窗口）→ 120s / 300s
- `idle`：GW 未开始，或上一 GW 已 sealed 且下一 GW 未开始 → **不轮询**，直接用缓存；上游也只发 4 个基础请求，不抓 picks

**踩到的坑**：
1. `manager_avatar` 双重拼接：`config.json` 里是裸文件名，`meta.json` 里已是 `assets/avatar/xxx.jpg`，
   `assemble()` 拿的是 meta 的 managers，又拼了一次前缀 → 加 `normalizeAvatarPath()` 按是否含 `/` 判断。
2. `finished → sealed` 需要跑**两次**采集才落定：`sealed_eligible` 要求详情文件已存在，
   而 run 时文件是本次才写的。差分校验前必须让 Python 侧到不动点，否则会看到一次性差异。
3. PowerShell 管道会把子进程 UTF-8 输出按 GBK 解码 → 先 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` 再跑。
4. `npm start` 曾经只起静态服务器（抓数据是 `npm run dev`）。现已改为 `start` = 抓取+启动，
   `serve` = 只起服务器，`live` = 挂实时接口预览。

**验证结果**：`npm run verify` 70 项全通过。含
① summary/stats/meta 与 Python 产出**逐字段零差异**；② 积分计算与 `stats.py` 逐位一致
（合成赛程覆盖 ①②③④⑤、取消资格、大型 BGW 例外、并列平分）；③ 状态机与前端回落/排程逻辑；
④ 接口状态码/CORS/缓存头。另用无头 Chrome（`--dump-dom`）实测两条数据路径：
`http://127.0.0.1:8081/` → 页脚「实时接口 · 已冻结，使用缓存」、GW4 显示 89 pts / OR 3,324,502；
`file://` → 「静态快照 · 未连接实时接口」，内容同样正确。

**部署注意**：仓库必须含基线 `data/meta.json` + `data/summary.json`（实时层需要起点），
已用 `git add -f data/` 纳入；GitHub Pages 无函数，靠 Actions 提交（且 60 天无活动会被自动停用）。
